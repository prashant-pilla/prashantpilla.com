## Problem

ADIN is an AI-first, community-powered venture network built by Tribute Labs: AI agents run diligence, members vote, scouts source deals and earn carry. Three very different audiences, investors, members, and founders, needed to understand it from one site.

## What I built

A responsive marketing site in Next.js 15 (App Router) with React 19, TypeScript, and Tailwind CSS 4. The home page carries an animated keyword hero, live report cards, a section for the five AI agent personas, a human network showcase, and a category-filtered FAQ. Dedicated `/investors`, `/members`, and `/founders` routes each explain the flow for that audience, including a real-time voting interface mockup and the deal submission and carry mechanics. Mobile-first layout, keyboard navigation, and screen reader support throughout.

## Outcome

Live on Vercel as ADIN's public site during its 2025 launch period.
